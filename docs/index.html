class biotools.fasta.Seq(sequence, header='')¶

Класс для хранения и анализа биологической последовательности.

Атрибуты:

NUCLEOTIDES (set): Множество символов нуклеотидов (A, C, G, T, U, N). PROTEIN (set): Множество символов 20 стандартных аминокислот. _sequence (str): Последовательность в верхнем регистре. _header (str): Заголовок FASTA-записи.

gc_content()¶

Вычисляет GC-состав (долю гуанина и цитозина) в процентах.

Возвращает:

float: Процентное содержание GC (от 0 до 100).

Исключения:

ValueError: Если последовательность не является нуклеотидной.

get_alphabet()¶

Определяет тип алфавита последовательности.

Возвращает:
str: «nucleotide», если все символы нуклеотиды;

«protein», если все символы аминокислоты; «unknown», если последовательность содержит смешанные символы.

header(group=None)¶

Читает заголовки файла (строки, начинающиеся с @).

Параметры:

group (str, optional) – Конкретная группа заголовков (например, «@SQ»). Если не указана, возвращает все группы.

Результат:

Если group=None, возвращает словарь со всеми группами.

Если group указана, возвращает список строк этой группы.

Тип результата:

dict или list
